Section 01

Gemini-plan 추출

Stage 1의 목적은 각 질문을 직접 box sequence로 답하는 것이 아니라, 뒤의 두 tracker와 sparse predictor가 공동으로 사용할 불변 tracking contract를 생성하는 것이다. 최종 test plan은 Vertex AI의 gemini-3.7-flash로 생성되었으며, multi_anchor_plan.json 하나가 질문 하나의 target ID, 존재 구간, prompt를 모두 고정한다.

Method

  1. 질문과 전체 video를 저비용 proxy로 변환. 원본에서 최대 192 frame을 균일 sampling하고 장변을 최대 512 px로 축소한다. 각 frame에 orig_frame=N을 burn-in한 MP4를 만들며 proxy FPS는 최대 6이다. Gemini video part의 sampling rate는 별도로 4 fps로 지정한다.
  2. answer noun phrase 추출. 질문이 요구하는 실제 물체/물체 집합을 간결한 시각적 명사구로 반환한다. 사람·손·팔은 target에서 제외하고 distractor와 구분되는 속성을 포함한다.
  3. critic verification. 두 번째 독립 호출이 질문을 다시 풀고 noun phrase를 correct/wrong으로 판정한다. 오류이면 noun phrase를 교체하며, 복수 물체 문제의 expected instance count를 anchor planner에 전달한다.
  4. stable identity와 anchor 선택. 각 실제 instance에 연속된 obj_id=0,1,…를 부여하고, visual_identity_description과 여러 visibility_segments를 만든다. 모든 target이 잘 보이는 한 frame을 우선하며 불가능할 때만 최대 3개의 최소 anchor set을 고른다. anchor frame은 stride-10 grid에 맞추고, 벗어난 응답은 가장 가까운 허용 frame으로 정렬한다.
  5. exact-frame box 추출. 선택한 원본 anchor image를 다시 제공하고 각 target마다 tight [ymin,xmin,ymax,xmax], 0–1000 box를 받는다. 모든 호출은 temperature 0, forced function calling(mode=ANY)과 Pydantic schema validation을 사용한다.
Plan = {question semantics, stable target IDs, visibility segments, anchor frames, anchor boxes}

Section 02

Gemini sparse tracking

Stage 2는 Stage 1을 다시 풀지 않는다. 저장된 target ID와 identity를 고정한 채 원본의 0, 30, 60, … frame에서 Gemini 3.7 Flash가 amodal box를 예측한다. 이 sparse grid는 occlusion 구간에서 SAM의 visible-mask drift를 보완하고, 신뢰 가능한 구간에서는 dense SAM의 시간 해상도를 받아들이는 기준 좌표계로 사용된다.

Sparse prediction method

  1. decoder-exact frame extraction. ffmpeg select=not(mod(n,30))으로 source frame을 한 번만 decode하여 JPEG로 cache한다. 단순 timestamp seek가 아니라 frame index 기반이므로 plan과 평가 좌표계가 일치한다.
  2. 8-frame bounded image batch. 기본 8장과 compact plan을 한 API call에 넣는다. temperature 0, thinking level high, max output 32,768 tokens, JSON response schema를 사용한다.
  3. amodal identity contract. 각 box는 정확히 한 target instance만 포함한다. hand/occluder/여러 target의 union box를 금지한다. partially_occluded이면 보이지 않는 부분까지 실제 full extent를 추정하고, fully_occluded이면 temporal context로 target 자체의 위치·크기를 추정한다.
  4. presence 해석. Stage 1의 visibility segment는 “보였던 구간”이지 물리적 presence가 아니다. segment 내부 ID 누락은 오류로 처리하지만 segment 밖의 hidden target을 자동 삭제하지 않는다. scene을 실제로 떠난 경우에만 해당 ID를 생략한다.
  5. strict validation 및 retry. frame 순서, known ID subset, ID 중복, visibly-confirmed ID coverage, 0–1000 양의 box를 검증한다. schema/validation 오류와 transient API 오류는 최대 3회 retry한다.

v13-style sparse-first fusion

sparse와 dense를 무조건 평균하지 않는다. 먼저 compact v7 export의 전-frame hold를 run_result.non_empty_frames ∩ segment_gating.intervals로 되돌려 실제 sampled SAM coverage를 근사한 뒤 target별 trust gate를 적용한다.

trusted = [IoU(seed, SAM) ≥ 0.25] ∧ [shared grid frames ≥ 3] ∧ [mean IoU(sparse, SAM) ≥ 0.30]
  1. gate 실패 target은 Gemini sparse grid만 사용한다.
  2. gate 통과 target은 sparse grid를 먼저 놓고 실제 SAM sampled frame으로 overlay한다.
  3. shared frame에서 IoU ≥ 0.30이면 residual r(t)=box_sparse(t)-box_SAM(t)를 만들고, SAM box 좌표에 시간 보간한다. 한쪽 anchor만 있으면 최대 60 frame까지만 residual을 전달한다.
  4. 빈 gap은 길이 ≤ 6이거나 두 endpoint box IoU ≥ 0.30일 때만 선형 보간한다. endpoint hold와 무조건 densify는 하지 않는다.
알려진 한계. pipeline-v7 compact JSON에는 target별 raw mask failure가 없으므로 sampled coverage 복원은 lossy이다. 한 frame에서 일부 target만 실패한 경우까지는 복구할 수 없다. 이 사실은 각 fusion_meta.json에 기록된다.

Section 03

SAM3 zero-shot tracking (pipeline-v7)

pipeline-v7은 학습 없이 official SAM3 PVS checkpoint를 사용한다. Stage 1 plan의 target ID, anchor frame, anchor box를 그대로 replay하므로 이 단계에서는 Gemini를 다시 호출하지 않는다. 최종 dense branch는 joint multi-object session, source stride 3, bidirectional propagation, visibility-segment gating으로 생성되었다.

Method

  1. adaptive sampled frame set. 기본 source frame 0,3,6,…에 모든 anchor, 마지막 video frame, 각 target visibility segment의 시작/끝 및 global first/last visibility 주위 ±15 frame의 stride-1 window를 합친다.
  2. 한 SAM3 session에 모든 box 등록. plan의 모든 anchor와 target box를 stable obj_id로 native instance-tracker box prompt에 등록한다. box는 corner points와 box labels로 변환된다.
  3. single bidirectional propagation. 모든 prompt를 등록한 후 한 번 전파한다. 시작 anchor는 sampled video 중앙에 가장 가까운 non-terminal anchor를 선택한다. terminal frame에서 시작하면 conditioning frame 외 mask가 나오지 않는 실패가 있어 대안 anchor가 존재할 때 terminal anchor를 제외한다.
  4. object-wise temporal gating. SAM3가 이미 사라진 유사 물체에 높은 confidence mask를 계속 내는 것을 막기 위해 각 target의 visibility segment ±15 밖 output을 제거한다.
  5. compact dense export. raw mask가 RAM에 있을 때 normalized XYXY box로 변환한다. sampled frame 사이에서는 historical v7 방식대로 previous-value fill, 첫 관측 이전은 first-value fill하여 전체 source frame에 box를 기록한다. 대용량 pickle은 저장하지 않는다. Stage 2 fusion은 뒤에서 이 hold를 sampled coverage로 다시 제한한다.

Section 04

SAM3 training version (amodal_train)

training branch는 official SAM3의 visible tracking 경로와 memory를 고정하고, SAIL-VOS의 visible/amodal annotation으로 작은 amodal mask-logit residual head만 학습한다. 최종 epoch-20 checkpoint를 Stage 1의 동일 Gemini box prompt에 적용하며, continuous-state + skip memory guard로 전체 video를 추론한다.

Training method

데이터와 causal contract

  • SAIL-VOS official RGB, native visible instance .npy, object별 amodal PNG 사용.
  • 10 train sequences / 4 disjoint validation sequences.
  • shot-aware manifest schema v2, shot MAE threshold 0.12, boundary guard 1 frame.
  • clip length 8, source stride 1, manifest가 정한 forward 또는 backward 방향.
  • clip 첫 frame은 반드시 PRESENT_VISIBLE이며 transformed visible bbox 하나만 prompt로 사용.
  • FULLY_OCCLUDED는 amodal positive로 취급하고 IGNORE는 loss에서 제외.

Residual architecture

backbone, visible decoder, 별도 복제한 amodal proposal decoder까지 모두 freeze한다. trainable branch는 image feature의 1×1 projection, visible/proposal logits를 함께 받는 3×3 refinement 2개, 1×1 output으로 구성된다. residual에는 tanh bound를 적용하고 frozen visible logit에 더한다.

Lamodal = clip(Lvisible, −16, 16) + 32 · tanh(H(F, Lvisible, Lproposal))

optimizer allowlist는 amodal_residual_head.*만 허용하며 나머지 parameter가 trainable이면 즉시 실패한다. frozen SAM3는 BF16 autocast로 실행하고 작은 residual head는 FP32로 계산한다.

Loss

Loss = 5 · Focal(amodal) + 5 · Dice(amodal) + 5 · Visible-Containment

IoU regression과 presence loss의 최종 weight는 0이다. containment loss는 visible support에서 amodal probability가 frozen visible probability보다 낮아지는 경우를 벌점으로 주어 visible ⊆ amodal 관계를 유도한다.

Continuous-state amodal inference

  1. 동일 Gemini prompts. zero-shot v7과 정확히 같은 plan의 anchor frame/box를 visible bbox mask로 사용한다. baseline mask나 amodal output을 prompt로 사용하지 않는다.
  2. target별 독립 pass. skip mode에서는 한 frame의 memory를 target별로 생략할 수 있어야 하므로 multi-object anchor를 object별 single-object pass로 분리한다.
  3. persistent state. anchor에서 forward/backward 방향을 각각 별도 TrackingState로 전파한다. 8-frame chunk는 backbone feature memory를 제한하는 계산 단위일 뿐, chunk 경계에서 state를 reset하거나 re-prompt하지 않는다. 각 pass의 첫 chunk만 Gemini box prompt를 갖는다.
  4. visible-memory skip guard. visible mask가 non-empty이고 presence probability ≥ 0.5이며 predicted IoU ≥ 0.5일 때만 reliable이다. unreliable non-conditioning frame은 mask memory encoding과 persistent output dictionary 기록을 모두 생략한다. amodal mask는 출력하되 다음 frame의 visible memory를 오염시키지 않는다.
  5. amodal output selection. 여러 anchor가 같은 frame을 예측하면 anchor distance가 가장 가까운 결과를 사용하고, plan segment ±15 안의 non-empty amodal mask를 normalized box로 변환한다. blind test는 모든 source frame을 요구하므로 sparse non-empty 결과를 nearest fill하여 dense track을 만든다.

# base = existing v7+Gemini prediction; amodal = merged trained-amodal+Gemini shards
for video_id, question_id in test_subset:
    sample = f"{video_id}_q{question_id}"
    plan = load_json(plan_root / sample / "multi_anchor_plan.json")
    question = plan.get("question", "")
    eligible = (
        len(plan.get("targets", [])) > 1
        and "occlusion game" not in question.lower()
        and question.strip()
            != "Track the objects shown to the camera more than once."
    )
    replacement = amodal[video_id]["grounded_question"].get(question_id)
    if eligible and replacement is not None:
        base[video_id]["grounded_question"][question_id] = replacement
        routed_samples.append(sample)
