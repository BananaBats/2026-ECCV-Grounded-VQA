# Source and artifact audit

This inventory was reconstructed from the two technical reports, the final
route manifest, file timestamps, final-output checksums, pipeline logs, and the
local command history that produced the submission.

## Included executable components

| Final stage | Included file(s) | Original source |
|---|---|---|
| Gemini noun/critic/anchor planning | `src/pipeline/box_baseline.py`, `multi_anchor_box_baseline.py` | `gemini-plan/code/box_baseline.py`, `pipeline-v7/multi_anchor_box_baseline.py` |
| Persistent zero-shot SAM3 replay | `persistent_test_worker.py`, `scripts/run_dense_tracking.sh` | `pipeline-v7/persistent_test_worker.py`, `run_test_persistent_multigpu.sh` |
| Dense submission merge | `merge_compact_predictions.py` | `pipeline-v7/merge_compact_predictions.py` |
| Sparse Gemini boxes | `generate_sparse.py`, `sparse_common.py`, `scripts/run_sparse.sh` | `gemini-plan/sparse-output/` |
| Reliability-gated fusion | `fuse_dense_sparse.py` | `gemini-plan/sparse-output/fuse_dense_sparse.py` |
| v13 fusion parity reference | `references/inhong_v13/fuse_v13.py` | `inhong/v13/fuse_v13.py` |
| Shard merge and 2-sample fallback | `merge_shards.py`, `finalize_fusion.py` | tracked merge source plus recovered finalization procedure |
| Selective routing | `route_predictions.py` | recovered from the exact one-off command that created `route_manifest.json` |
| Submission validation | `validate_submission.py` | recovered from the final structural validation command |

Copied algorithm sources retain the implementation used in the run. Only local
path discovery was changed so the bundle does not refer to the original
workspace or to an amodal-training directory. Portable launch scripts expose
those paths through environment variables.

## Included direct inputs and results

- 1,859 `multi_anchor_plan.json` files consumed by dense replay, sparse
  inference, fusion, and routing, packed in `inputs/plans_test.tar.gz`.
- 1,857 successful `sparse_predictions.json` files, packed in
  `inputs/sparse_predictions_test.tar.gz`.
- `config/test.tsv` with all 1,859 question keys.
- Zero-shot dense, zero-shot fused, and final routed predictions as gzip
  artifacts.
- The complete route manifest (with local paths normalized), fusion completion
  summary, input audit, technical report, and SHA-256 inventory.
- Dense fallback for the two missing sparse samples:
  `video_7360_q5` and `video_7567_q5`.

Generated proxy videos, extracted PNG/JPEG frames, prompt/call logs, caches,
temporary files, visualizations, and per-sample duplicate dense JSON were
audited but not copied. They are either regenerated by the included code or
redundant with an included canonical artifact. The raw directories were about
16 GB for plan reproductions and 15 GB for sparse runs, mostly images/video.

## Explicitly excluded by request

- Amodal fine-tuning source code and experiment code.
- Amodal training datasets, manifests, losses, and trainer configuration.
- Trained residual-head checkpoints and model weights.
- Amodal-trained inference implementation and intermediate dense output.
- The alternate amodal-fused prediction shards consumed by the final router.
- Third-party SAM3 source, official checkpoint, CUDA/PyTorch environment, VQA
  dataset videos/annotations, Google credentials, and caches.

Because the alternate branch is excluded, the repository can reproduce the
complete zero-shot 0.6620 path directly. The exact 0.6637 routed result remains
available in `artifacts/final_predictions.json.gz`; regenerating it through the
router requires supplying the intentionally excluded alternate predictions.
